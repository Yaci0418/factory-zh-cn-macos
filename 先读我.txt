Factory Desktop 简体中文补丁（macOS v1.0.1 修正版）
==========================================

验证：Factory Desktop 1.3.0、Apple Silicon Mac（arm64）独立副本。
安装、恢复及实际签名校验已通过；GUI 验证范围见 CHANGELOG.md。
不是浏览器插件，也不需要导入 Factory 的插件管理页。

只想安装：
1. 安装 Node.js 18 或更高版本：https://nodejs.org/
2. 把整个 ZIP 解压，所有文件保持在同一个文件夹内。
3. 保存工作，用 ⌘Q 完全退出 Factory。
4. 双击“一键汉化.command”，按终端提示继续。
5. 安装成功后自己打开 Factory。
6. 打开 Settings → Preferences → Language，选择“简体中文”。

本补丁不会自动退出或启动 Factory，不使用 launchd。
正常使用预打包补丁不需要运行 npm install 或 npm ci。

恢复英文：
先完全退出 Factory，再双击“恢复英文原版.command”。
它恢复程序文件，但不能恢复官方代码签名。

安装报错、没有执行权限或想用命令行：
请阅读同目录 README.md 的完整步骤。
不确定错误原因时停止，不要直接使用 sudo 或关闭系统安全功能。

开发者：
请阅读 DEVELOPING.md，源码在 src/patcher.js，词典在 translations/zh-CN.json。

重要风险：
安装会修改 Factory.app，并把官方代码签名替换为 ad-hoc 签名。
权限或签名失败可能使应用无法启动，必要时重新安装官方 Factory。
Factory 更新可能覆盖补丁。非官方项目，请自行评估风险。
